# Tasks

## Task 1: Gate examples to top-level builds by default

### Goal

Prevent downstream `add_subdirectory` and `FetchContent` consumers from building demo targets unless explicitly requested.

### Scope

- Root `CMakeLists.txt`

### Implementation

- Introduce a top-level-sensitive default for `QTMATERIALWIDGETS_BUILD_EXAMPLES`.
- Keep the existing option name so direct builds can still override it.

### Validation

- Configure the repository directly and confirm `examples` remains enabled by default.
- Configure a parent project with `add_subdirectory(...)` and confirm `examples` is not generated by default.

## Task 2: Make Core safe for shared-library linkage on non-Windows

### Goal

Ensure `QtMaterialWidgetsCore` can be linked into `QtMaterialWidgets` on Linux and macOS.

### Scope

- `components/CMakeLists.txt`

### Implementation

- Enable `POSITION_INDEPENDENT_CODE` on `QtMaterialWidgetsCore`.

### Validation

- Reconfigure and rebuild the repository successfully.
- Confirm the Core target still links into the shared library target.

## Task 3: Re-run package consumption checks

### Goal

Verify the two fixes do not break the exported package path.

### Scope

- Build/install outputs
- Minimal external consumer project

### Implementation

- Install the package to a local prefix.
- Build a minimal consumer through `find_package(QtMaterialWidgets CONFIG REQUIRED)`.

### Validation

- Consumer configure succeeds.
- Consumer build succeeds.
